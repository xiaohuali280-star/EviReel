# 学习区与 AI 助手可拖动分栏设计

日期：2026-10-23（Asia/Shanghai）

状态：A–F 已完成并上传 `main`，本地验收和 [GitHub CI](https://github.com/xiaohuali280-star/EviReel/actions/runs/39953222479) 均通过。实现与验证见 [交付记录](RESIZABLE_WORKSPACE_DELIVERY.md)。

## 1. 当前布局与目标

已核对 `frontend/src/App.tsx`、`style.css` 和现有浏览器测试。当前 `.columns` 为两列网格：学习区弹性占宽，AI 助手通常为 350–400px，大屏为 450px；两列间距为 12–20px。900px 及以下改为上下排列。当前没有可拖动分界线，仓库工作区干净，远端 main 与本地一致。

目标是在中间学习区与右侧 AI 助手之间加入可拖动分界线。左侧导航保持现有宽度，两块内容在其余可用空间内按比例分配。

## 2. 视觉与鼠标操作

- 保留现有蓝白/深色外观和两栏间距。间距中央设置约 12px 的透明拖动命中区，常态仅显示低对比细线或短把手。
- 鼠标悬停时，指针变为标准左右调整宽度光标 `↔`（`col-resize`），分界线变蓝，显示“左右拖动调整宽度，双击恢复默认”提示。
- 按住拖动：向左移动，AI 助手变宽、学习区变窄；向右移动，学习区变宽、AI 助手变窄。两栏实时重新排版。
- 拖动期间禁止文字选中，分界线保持高亮；结束后恢复正常选择与光标。双击恢复默认比例。
- 这里调整的是容器宽度；视频按自身比例适配，文字重新换行，不使用整体缩放，不拉伸视频画面。

## 3. 比例、边界与记忆

定义 W 为扣除左侧导航、页面内边距、分界间距后，两块内容可分配的总宽度。

- 默认：学习区 65%，AI 助手 35%。首次进入和“恢复默认”使用该比例，再按最小宽度限制修正。
- 建议可调范围：学习区 40%–75%，AI 助手 25%–60%。同时要求学习区至少 420px、AI 助手至少 320px；最终边界取比例与最小像素限制的交集。
- 拖到边界自动停止，两栏不互相覆盖，不产生整页横向滚动。聊天工具栏、输入框和四功能卡片在窄宽下适配换行，必要时卡片变成单列。
- 使用实际容器测量计算比例，不能直接拿整页宽度计算。窗口大小变化时重新限制实际宽度，保留用户最后偏好的比例；临时缩小窗口不覆盖偏好。
- 松手后将偏好保存至本机浏览器 `localStorage`，切换视频、新建会话、刷新后沿用。不按视频分别存储，不增加后端配置或额外模型调用。存储失败仍可在当前页面调整；存储值损坏时回到默认。
- 900px 及以下继续上下排列并隐藏分界线；即使视口更宽，实际空间不足以满足两栏最小宽度时，也使用上下排列。返回宽屏后恢复之前的偏好。

## 4. 拖动稳定性与无障碍

- 新增独立分栏组件/Hook，负责尺寸、指针、键盘和偏好；聊天、播放器及任务状态继续由现有 App 管理。
- 使用 Pointer Events 和指针捕获，使鼠标拖出分界线后仍能继续调整；鼠标松开、指针取消、组件卸载时清理拖动状态。Escape 取消当前拖动并恢复本次拖动前的比例。
- 调整用动画帧合并更新，不在每次移动时写入本地存储。拖动时不使用宽度过渡动画，防止延迟跟手。
- 布局调整不改变视频和聊天组件的身份，不重建播放器、不重连聊天、不重发请求、不清空草稿或重置已有消息。视频播放、上传及后台任务继续运行。
- 分界线支持 Tab 聚焦，使用 `role=separator`、垂直方向、控制对象与当前比例等可访问属性，提供清晰焦点样式。
- 左/右方向键每次调整 2 个百分点；Shift+方向键为 5 个百分点；Home/End 到达当前可用边界；Enter 恢复默认。
