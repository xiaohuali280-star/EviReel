## 真实能力边界

本次流程验证注入明确的测试 ASR/模型适配器；真实音视频、数据库、媒体接口和导出器参与测试。没有使用真实付费模型密钥，没有将 Mock 结果称为真实课程质量验收。生产入口不加载测试适配器。

自动笔记仅在配置模型且启用 STUDY_AUTO_GENERATE 时启动；有预算和超时。来源校验保证引用身份与完整材料覆盖，不保证总结事实无误。语音文稿未经人工校对，不包含说话人分离和逐词时间。课件为文本学习课件，没有声称自动复刻原课程 PPT。PPTX 在本机做结构/文字/边界参数检查，未通过 PowerPoint/LibreOffice 实际渲染；PDF 已实际渲染核对。PDF 中文 CID 字体、PPTX 中文字体的最终外观受阅读器字体支持影响。

本次没有新增登录、跨视频问答、联网搜索或任意附件问答。旧 DELETE API 仍为永久删除，网页通过回收站确认入口使用。对外部署的认证/HTTPS 由运营配置，应用继续采用单 worker。
