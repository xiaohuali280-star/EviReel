# 左侧导航栏最小化交付记录

日期：2026-10-23（Asia/Shanghai）。按用户已审核的 [设计方案](COLLAPSIBLE_SIDEBAR_PLAN.md) 实施，直接在 `main` 开发。

## 已实现与使用方法

点击 EviReel 品牌右侧的“收起侧边栏”，桌面导航栏缩为 72px 图标栏；点击“展开侧边栏”恢复当前屏幕原有宽度。Logo 仍返回首页，折叠按钮独立操作。

- 收起后保留上传、我的视频、回收站及底部空间标识。上传直接选择文件；点击分类图标展开对应视频列表，继续访问恢复、删除、分页等原功能。
- 图标按钮保留明确的可访问名称、悬停/键盘焦点提示和当前分类高亮。展开状态提供 aria-expanded；隐藏列表退出键盘访问，跨屏幕切换或手机选择视频导致列表隐藏时，焦点回到展开按钮。
- 桌面偏好保存在 `evireel:sidebar-collapsed`；默认展开，刷新、切换视频与新建会话后沿用。非法值或存储访问失败时回到默认；保存失败仍可在当前页面操作。
- 600px 及以下使用一行紧凑顶部工具条，默认收起列表。点击分类或展开按钮显示列表，选择视频后收起；移动端临时状态不覆盖桌面偏好。
- 侧栏展开/收起后，已有分栏根据实际可用空间重算宽度，保留用户比例偏好和最小宽度限制；窄屏继续上下排列。
- 只改变布局与本地导航呈现，不重新挂载播放器、不清空草稿、不重发聊天请求。上传、索引及学习任务沿用原生命周期。视频列表保持 DOM 身份，并记录/恢复滚动位置。
- 宽度即时切换，避免尺寸过渡导致滚动位置被中途收窄的列表截断；浅色和深色主题均适配。没有新增依赖、后端接口或数据库结构。
