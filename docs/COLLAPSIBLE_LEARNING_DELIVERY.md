# 笔记与文稿区域最小化交付记录

日期：2026-10-24（Asia/Shanghai）。用户授权本轮设计、实施、验证并直接上传 `main`；[方案](COLLAPSIBLE_LEARNING_PLAN.md) 已记录。

## 使用与行为

- 播放器下方默认只显示“章节与笔记”“文稿”和向下展开按钮；正文、章节、生成状态、刷新和下载工具收起，不占正文高度。
- 点击任一标题向下展开对应内容；展开时点击另一标题切换，点击当前标题再次收起。右侧箭头按钮可随时收起或重新展开最近查看的内容，提供明确的展开/收起名称。
- 聊天资料卡“在学习区查看”自动展开对应笔记或文稿；生成完成和后台轮询不会强制展开。每次刷新、首次进入或切换视频默认收起。
- 同一视频暂时收起时不卸载当前正文，保留已选章节和已读取文稿；文稿首批读取在实际展开时发生，重复展开复用已加载内容。生成任务和下载仍使用原有功能。
- 播放器、聊天及后台任务保持独立；切换收起状态不改变视频节点、播放位置、草稿或在途问答请求。
- 原生按钮支持 Tab 和 Enter/空格，提供 aria-expanded、aria-controls，内容区域以当前标题命名；收起区域退出键盘与读屏访问。手机控制栏缩小间距，兼容侧栏最小化、两栏拖动及深浅主题。
