## 页面约定

- 采用蓝白三栏：视频导航、学习内容、AI 助手；上传前与处理中的右栏保持同一欢迎视图。
- 欢迎视图保留自动生成笔记、AI 看视频、生成文稿、生成课件、四条推荐问题和当前视频范围提示。
- 上传进度与处理阶段分开；处理中统一显示“视频正在处理中”，不向普通用户拆开画面索引与语音转写，也不伪造总百分比。
- 学习详情使用“章节与笔记”“文稿”，删除“目标示意”等设计注释。
- 状态由真实接口决定。无音轨、失败、旧版证据、未就绪、断线和重启均有明确反馈。

## 后端设计与边界

业务库升至 schema 4：增加软删除时间、独立 study_jobs 与 study_artifacts；不混用 video/transcript 索引任务。
生成任务固定来源版本，优先使用可读字幕片段，缺字幕时回退实际视觉事件；没有可用文字内容时明确失败。每批输入、输出、总批次、超时及并发有上限；模型只生成标题/知识点，时间和引用由程序从真实来源构造。较长视频超过预算时返回明确错误，不伪称整课完成。
产物一次事务发布；失败保留旧成品，重启标记中断，用户用新请求 ID 重试。来源重建后旧成品可读取并标为旧版。
自动笔记在索引完成后按配置启动；有付费模型配置时会调用该提供商，提供关闭自动生成的配置。真实质量与费用独立验收。
文稿保留 ASR 原文；PPTX/PDF 由已发布章节产物导出，明确引用与来源时间。
头像作为本地工作区标识。附件入口只说明支持范围；本次仍采用视频上传与当前视频问答，没有隐式新增跨视频联网搜索或多用户账号。

## 验收出口

每项以可操作功能和测试为准。浏览器 Mock 模式仅显式测试启动，生产默认禁用；Mock 全链路不等同真实模型效果。
前端不得从回答 Markdown 提取定位时间，不执行模型生成的任意资源链接；视频与会话切换过滤迟到结果，恢复按 request_id 合并。
回收站保留文件与关联数据；永久删除才级联清除。旧 DELETE API 兼容原语义，前端移入回收站使用新接口。
构建、后端回归、浏览器流程通过后生成交付报告，说明实际验证与尚未验证的真实模型效果。
