# 可拖动分栏交付记录

日期：2026-10-23（Asia/Shanghai）。按用户已审核的 [设计方案](RESIZABLE_WORKSPACE_PLAN.md) 实施，直接在 `main` 开发。

## 使用方式

将鼠标移到学习区与 AI 助手之间的细线，指针变为左右调整光标，细线高亮。按住向左拖动扩大助手，向右拖动扩大学习区；松手保存当前比例。双击恢复默认的学习区 65% / 助手 35%，实际宽度同时满足最小尺寸限制。

分界线可用 Tab 聚焦：左右键调整 2 个百分点，Shift+左右键调整 5 个百分点，Home/End 到当前边界，Enter 恢复默认。拖动中按 Escape、取消指针或窗口失焦会撤销本次拖动，恢复拖动前比例并清理选择锁和光标。

## 实现

- 新增纯尺寸计算模块与独立 Hook；现有 App 只接入容器和分界线，播放器与助手继续保持原组件身份。
- 使用真实容器可分配宽度计算比例。学习区范围 40%–75%，且至少 420px；助手至少 320px。达到边界自动停止，不把最小宽度冲突转成横向滚动。
- `ResizeObserver` 检查窗口/容器变化；900px 及以下或实际宽度不足时隐藏分界线并上下排列。窄窗口不会覆盖宽屏偏好，回到宽屏后恢复。
- 偏好保存在本地 `evireel:panel-ratio`。只在结束拖动或键盘调整时保存；拒绝非法数字。存储损坏、不可访问或写入失败时仍可使用页面和调整宽度。
- Pointer Events 与指针捕获让鼠标越过视频及拖动区域后继续控制分界线。动画帧合并移动更新，结束与卸载清理监听和未执行帧。
- 分界线提供 separator 语义、垂直方向、关联面板、当前比例与边界，支持焦点轮廓。助手卡片和章节笔记根据所在面板宽度自动换行或单列显示，适配浅色和深色主题。
- 仅改变布局。没有新增后端接口、依赖、模型调用或聊天重连逻辑；切换视频、新建会话不重置分栏偏好。同步生产静态页面资源。
