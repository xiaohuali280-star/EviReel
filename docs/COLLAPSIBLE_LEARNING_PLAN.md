# 笔记与文稿区域收起/展开方案

日期：2026-10-24（Asia/Shanghai）。用户已授权本轮设计、实现、测试并上传 `main`。

## 交互

- 播放器下方保留现有“章节与笔记”“文稿”名称，默认只显示这一行入口和向下展开按钮。章节、正文、状态提示、生成/下载工具均收在下方，未点击时不占正文高度。
- 点击“章节与笔记”或“文稿”，向下展开对应内容；展开时点击另一入口切换内容，点击当前入口可收起。右侧统一提供“展开笔记和文稿/收起笔记和文稿”按钮，收起后仍可重新展开最近查看的内容。
- 点击聊天资源卡的“在学习区查看”属于明确查看操作，自动展开对应笔记/文稿。后台任务完成、消息返回、页面轮询不擅自展开。
- 每次刷新、首次进入视频或切换视频默认收起；同一视频暂时收起再展开保留已选章节和已加载文稿。收起不会重置播放器、草稿、对话或后台任务。

## 实现

- 在现有 App 中增加独立展开状态和统一选择入口；复用现有 tab、学习任务、文稿及下载逻辑，不新增后端接口或依赖。
- 原正文包裹在可隐藏的语义区域内。收起不卸载当前正文，不丢失已加载内容；隐藏区域不参与键盘焦点或读屏访问。文稿首批读取延迟到实际展开文稿时，后台语音处理保持原流程。
- 两个入口和收起按钮均使用原生按钮，提供 aria-expanded、aria-controls 和明确名称；支持 Tab、Enter/空格。箭头表达展开方向，收起按钮不会与刷新按钮混淆，刷新仅在展开时显示。
- 保持浅色/深色主题、窄屏布局、左侧最小化和两栏拖动兼容；控制栏在窄屏仍可完整操作，不产生整页横向滚动。
