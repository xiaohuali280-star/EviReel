# EviReel 左侧导航栏最小化设计

日期：2026-10-23（Asia/Shanghai）

状态：用户已审核，A–E 及 F 的本地验收已完成，正在上传 `main` 并核对 GitHub CI。结果见 [交付记录](COLLAPSIBLE_SIDEBAR_DELIVERY.md)。

## 1. 目标与当前布局

将最左侧 EviReel 导航栏收起为窄图标栏，为视频学习区和 AI 助手释放空间，随时可以展开。

已核对现有实现：左栏包含品牌、上传视频、我的视频、回收站、视频列表/管理操作、分页和底部学习空间标识；桌面宽度按屏幕为 185/224/250px，手机端已改为顶部区域。学习区与助手已有独立拖动比例和容器宽度监听。

## 2. 推荐交互

品牌区域增加独立的“收起侧边栏”按钮，使用侧栏折叠图标。收起后显示“展开侧边栏”按钮，始终可见且可点击。品牌 Logo 保留原返回首页行为，不把 Logo 点击改为折叠。

| 内容 | 展开状态 | 最小化状态 |
| --- | --- | --- |
| 左栏宽度 | 保留当前屏幕对应的原宽度 | 桌面统一 72px |
| 品牌 | Logo 与 EviReel 名称 | 仅 Logo，另保留展开按钮 |
| 上传视频 | 图标与文字 | 图标按钮，点击直接选择视频 |
| 我的视频 | 图标、文字与数量 | 图标和当前选中高亮，悬停/聚焦显示说明 |
| 回收站 | 图标与文字 | 图标和当前选中高亮，悬停/聚焦显示说明 |
| 视频列表、管理操作与分页 | 维持当前呈现 | 隐藏，展开后继续操作 |
| 底部学习空间 | 当前完整内容 | 仅 E 标识，提示“我的学习空间” |

最小化时图标按钮至少保留 40px 的点击区域，不把整段文本挤成竖排。点击“我的视频”或“回收站”图标时，展开对应列表，沿用原导航行为，避免用户找不到视频管理入口。恢复、永久删除等操作仍在展开后的列表中按现有流程进行。

## 3. 状态、记忆与两栏联动

- 桌面默认展开；用户收起/展开偏好保存在本地浏览器 `evireel:sidebar-collapsed`，刷新、切换视频和新建会话后沿用。只接受明确的合法值；存储损坏或不可用时回到默认，页面仍可操作。
- 单纯收起/展开不跳转首页，不清空当前视频、搜索、分页、章节、聊天草稿和历史；展开后恢复列表状态，尽量保持原列表滚动位置。
- 导航栏宽度改变后，中间学习区和右侧助手使用新增的可用空间；保留用户设置的两栏比例，只按现有最小宽度限制修正实际尺寸。再次展开时仍保留该比例偏好。
- 宽度不足时继续按既有规则上下排列；只有视口大于 900px 且实际空间足够时才左右排列。不能因为左栏收起而绕过两栏的最小宽度限制。
- 收起/展开不重新挂载播放器、不重连聊天、不重发模型请求，不打断上传、语音处理、笔记生成或其他后台任务。
- 实现采用即时宽度切换，保留按钮的轻量交互反馈；避免过渡过程中列表尺寸变化干扰滚动位置恢复。兼容现有浅色与深色主题。

## 4. 手机和平板

- 600px 以上：使用展开导航栏或 72px 图标栏，包括目前内容上下排列的平板场景。
- 600px 及以下：延续顶部导航布局，默认呈紧凑工具条，保留展开、上传、我的视频和回收站入口，不在左侧预留 72px 空栏。
- 手机点击展开后显示列表与管理入口，选择视频后可以收起列表，释放纵向空间；按钮点击和选择视频不应被误判成关闭操作。
- 手机的临时展开状态与桌面收起偏好分别管理；从手机尺寸回到桌面时恢复桌面偏好，自动适配不覆盖用户保存的选择。

## 5. 键盘和可访问性

- 折叠按钮支持 Tab 聚焦和 Enter/空格操作，提供“收起侧边栏/展开侧边栏”的清晰名称、`aria-expanded` 和关联内容标识。
- 所有仅图标按钮均提供可读名称；悬停和键盘聚焦显示对应说明，不能只依赖图标猜功能。
- 隐藏的视频列表、分页和管理按钮退出 Tab 顺序，不留下不可见焦点。若窗口切换导致当前聚焦区域隐藏，焦点回到展开按钮。
- 激活状态继续区分我的视频与回收站；不增加容易与聊天输入冲突的全局快捷键。
